# CVE researcher leaderboard (partial) — last 90 days

> **Data window:** CVEs published 2026-08-22 → 2026-11-20 · **Generated:** 2026-11-20
> **Methodology:** NVD CVE API 2.0 queried for CVEs in the window with CVSS v3 CRITICAL severity (292 records; v4-CRITICAL query returned none extra). Ranked by NVD CVSS base score (v4.0 if present, else v3.1/3.0; Primary score preferred), tie-break CISA KEV listing, then reference count, then recency. Cross-referenced with 2899 GitHub-reviewed advisories in the same window for GHSA IDs and researcher credits. CVSS scores, KEV flags and counts come from the cited sources (NVD, CISA KEV, GitHub Advisory Database) and are not independently scored.

> **Scope — partial leaderboard:** counts only GitHub-reviewed advisories published in the window that credit a GitHub user as **finder / reporter / analyst** (maintainer, coordinator and remediation credits excluded). NVD and most vendor CNAs do not publish per-researcher credit, so researchers credited elsewhere are missing. 1270 credited handles found; top 50 shown.
> **Profile links:** GitHub profile from the advisory credit; name, website and X are only what each person self-lists on their public GitHub profile. LinkedIn shown only when that self-listed website is a LinkedIn URL. No other links were searched for or inferred.

> **Also in this refresh:** [Newly listed CVEs](new-cves.md) — independent of researcher credit. Covers every CVE added to the [CISA KEV catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) between 2026-11-06 and 2026-11-20, plus Critical CVEs **published** in that same window with an NVD CVSS base score of 9.8 or higher (same score-selection rules as this leaderboard). Each entry has a plain-language summary, impact, sourced patch/fixed version, and update steps. Facts are linked to NVD, [cve.org](https://www.cve.org/), GitHub advisories, CISA KEV, OSV, and vendor advisories.
