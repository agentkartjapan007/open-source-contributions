# CVE researcher leaderboard (partial) — last 90 days

> **Data window:** CVEs published 2026-07-25 → 2026-10-25 · **Generated:** 2026-10-25
> **Methodology:** NVD CVE API 2.0 queried for CVEs in the window with CVSS v3 CRITICAL severity (407 records; v4-CRITICAL query returned none extra). Ranked by NVD CVSS base score (v4.0 if present, else v3.1/3.0; Primary score preferred), tie-break CISA KEV listing, then reference count, then recency. Cross-referenced with 2904 GitHub-reviewed advisories in the same window for GHSA IDs and researcher credits. CVSS scores, KEV flags and counts come from the cited sources (NVD, CISA KEV, GitHub Advisory Database) and are not independently scored.

> **Scope — partial leaderboard:** counts only GitHub-reviewed advisories published in the window that credit a GitHub user as **finder / reporter / analyst** (maintainer, coordinator and remediation credits excluded). NVD and most vendor CNAs do not publish per-researcher credit, so researchers credited elsewhere are missing. 1223 credited handles found; top 50 shown.
> **Profile links:** GitHub profile from the advisory credit; name, website and X are only what each person self-lists on their public GitHub profile. LinkedIn shown only when that self-listed website is a LinkedIn URL. No other links were searched for or inferred.
