# Open Source Contributions

Welcome! This is where we keep track of the open-source work we do and share it openly.

## Why this exists

We contribute to open-source projects, and we want one simple, honest place to record that work: what we changed, where, and a link to the source so anyone can check it.

## What belongs here

- **Merged pull requests** — CI hardening, tests, docs, bug fixes, and other improvements that were accepted upstream.
- **Public security advisories we are credited on** — links to published [GHSA](https://github.com/advisories) or CVE records that already credit us by name or handle.
- **Notes and write-ups** — short context about a contribution, always with a link back to the original PR or advisory.

Every entry should be checkable by someone else. If we cannot point to a public source, it does not go here.

## What does not belong here

- Unpublished vulnerabilities or private disclosure write-ups before the vendor says it is okay to share.
- Exploit proofs of concept for bugs that do not yet have a fix.
- Claims of credit without a public advisory, CVE, or merged PR that shows it.
- Invented or unverified CVE IDs.

We only document work that is already public and attributable.

## How we track things

See [`contributions/`](contributions/) for the tracker. Add a row to the CSV when a PR merges or a public advisory that credits us goes live. Keep the note short and link to the source.
